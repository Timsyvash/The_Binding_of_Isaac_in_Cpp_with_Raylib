🩸 The Binding of Isaac (Raylib C++ Edition)
2D-екшен у жанрі Roguelike, натхненний культовою грою The Binding of Isaac. Проєкт розроблено на мові C++ із використанням графічної бібліотеки Raylib. Гравець досліджує випадкові кімнати, бореться з монстрами за допомогою сліз, використовує бомби для руйнування перешкод та намагається дістатися порталу на наступний рівень.

🎮 Основні механіки
Переміщення та стрільба: Керування персонажем у реальному часі та стрільба сльозами під кутом.

Генерація кімнат: Завантаження процедурних/текстових карт із заблокованими плитками та ворогами.

Система вибухів: Бомби наносять шкоду ворогам, гравцю та руйнують перешкоди (блоки) на карті.

Різноманітні вороги: Спавн унікальних типів монстрів (Monstro, Gaper, Pooter) із власними алгоритмами поведінки.

Аудіосупровід: Повноцінні звукові ефекти для пострілів, вибухів та отримання шкоди.

🛠 Технології
Мова програмування: C++17

Графічна бібліотека: Raylib

Середовище розробки: Visual Studio (MSVC)

Система збірки: Visual Studio Solutions (.slnx / .vcxproj) / NuGet

🕹 Керування
W A S D — Переміщення гравця

ЛКМ (Ліва кнопка миші) — Стрільба сльозами у напрямку курсора

E — Закласти бомбу

R — Перезапустити гру (після поразки або перемоги)

Передумови
Встановлена Visual Studio 2022 (або новіша) із компонентом Desktop development with C++.

Пакет Raylib (автоматично підтягується через NuGet або локальну папку packages/).

Кроки для збірки:
Клонуйте репозиторій:

Bash
